# 🛍️ E-Commerce App

A full-stack **E-Commerce Web Application** built with the **MERN Stack**, featuring separate **Frontend**, **Backend**, and **Admin Dashboard**. The application provides a complete online shopping experience with product management, order processing, and an administrative control panel.

🌐 **Live Demo:** https://ecommerce-frontend-o67jset3v-natinael6570-8078s-projects.vercel.app/

---

## 📖 Overview

This project is a complete e-commerce solution that allows customers to browse products, place orders, and manage their shopping experience, while administrators can manage products, orders, and users through a dedicated admin dashboard.
